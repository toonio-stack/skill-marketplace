# skill-marketplace

Marketplace de skills portables pour agents IA (toonio-stack).

## Installation

Copie le dossier `skills/<nom-skill>/` dans le répertoire `skills/` de ton agent (ou suis le mécanisme d’install de ton runtime).

## Skills

| Skill | Description |
|-------|-------------|
| [create-agent](skills/create-agent/SKILL.md) | Concevoir et générer un package d’agent portable selon le standard The Boss |

## Contribution

Ajoute une skill sous `skills/<id>/` avec un `SKILL.md` (frontmatter `name` + `description`), puis ouvre une PR.
